### Slide 2：行业痛点与市场机遇
*   **标题**：为什么90%的量化策略会在极端行情中失效？
*   **痛点分析**：
    *   **数据孤岛**：单纯依赖K线（价量）无法捕捉X（推特）情绪、突发政策、宏观流动性的突变（DXY、10Y、WTI）。
    *   **响应延迟**：人工交易无法在数秒内同时处理新闻、KOL喊单和链上异动。
    *   **拥挤踩踏**：缺乏对盘口失衡（Orderbook Imbalance）和拥挤度的过滤，容易在高位接盘。
    *   **缺乏闭环**：传统策略更新慢，无法根据历史KOL胜率和市场反馈自动进化。
*   **市场机遇**：加密货币与宏观联动日益紧密（如美联储政策），谁能最快融合“宏观+微观+情绪”，谁就能掌握定价权。

### Slide 3：解决方案：新一代事件驱动引擎
*   **标题**：不仅仅是一个交易机器人，而是全方位的金融市场雷达
*   **核心逻辑（对应系统流程图）**：
    *   **感知层**：Price/OI/Vol 异动监控 + X大V + 政策 + 新闻。
    *   **认知层**：KOL Score + Policy Score + Impact Score。
    *   **决策层**：事件融合（Event Fusion） -> 市场确认（Market Confirm） -> 拥挤度过滤（Crowding Filter） -> 入场评分（Entry Score）。
    *   **执行层**：LONG/SHORT/WATCH -> 模拟盘自动执行（Paper Auto Execute）。
    *   **风控层**：30%仓位分配 -> 固定止损1% / 移动止损0.8%。
    *   **进化层**：交易结果反馈 -> 历史学习（Historical Learning）。
